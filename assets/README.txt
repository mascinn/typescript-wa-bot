Taruh foto jadwal petugas di folder ini dengan nama:

    jadwal.jpg   (atau jadwal.jpeg / jadwal.png)

Bot akan mengirim foto ini SEKALI ke grup, lalu semua reminder
akan membalas (reply) foto tersebut.

Jika foto diganti, bot otomatis mengirim foto baru saat restart/reconnect.
Admin grup juga bisa memaksa kirim ulang dengan command /kirimjadwal.
